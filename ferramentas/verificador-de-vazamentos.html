Verificador de vazamentos de senha

Descubra se uma senha já apareceu em bases de dados de vazamentos conhecidas usando uma consulta segura por k-anonymity.

🔒
Sua senha não é enviada ao SenhaLab

A senha é processada localmente no seu navegador. Para a consulta de vazamentos, utilizamos uma técnica chamada k-anonymity, que permite consultar a base sem enviar a senha completa.

Nunca digite uma senha que você não esteja disposto a analisar. O SenhaLab não armazena a senha informada.

Status da consulta Aguardando senha
• Aguardando análise
Digite uma senha para iniciar a verificação.
🔎

Como funciona?

A senha é transformada em um código criptográfico no próprio navegador. Apenas uma pequena parte desse código é utilizada na consulta.

A senha completa nunca é enviada ao serviço de consulta.

🛡️

O que significa o resultado?

Se a senha for encontrada, significa que ela já apareceu em uma base de dados de senhas comprometidas.

Nesse caso, recomendamos não utilizar essa senha em nenhuma conta.
